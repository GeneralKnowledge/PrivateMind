# Helper playbooks (agent-maintained)

The executive adds markdown playbooks here for operators, donors, and other helpers.

Start from the template in [../DONOR_AND_HELPER_INSTRUCTIONS.md](../DONOR_AND_HELPER_INSTRUCTIONS.md).

**Suggested first files (you create when ready):**

- `solo-operator.md` — help without provisioning keys
- `compute-donor.md` — worker only
- `key-donor.md` — scoped API keys on a paired worker

Empty on purpose until the agent writes them.
