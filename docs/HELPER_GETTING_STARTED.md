# Helper — getting started (no servers)

You help the **operator and agent** without donating VMs or API keys.

Examples:

- Review or merge draft PRs (if the operator delegates)
- Reproduce a bug on your laptop
- Answer a question on an assistance thread
- Point DNS or TLS at an agent hostname the operator owns
- Skim a doc for clarity

Open the operator’s **portal** → helper instructions. The agent may maintain a **non-key menu** in `docs/helpers/solo-operator.md` when it writes one.

You never need the vault passphrase.
